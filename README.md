Website that centralises university events and routes each one through an approval workflow before it goes public.

## Approval workflow
1. **Laboratory service** submits the event
2. **Vice-dean's office** reviews it
3. **Cultural affairs** approves or rejects it
4. **Economat** publishes it to the homepage

Students and teachers browse the published events.

## Stack
